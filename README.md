# 큐비 도감 (Cubie)

새 차의 기능 하나하나를 차 안에 사는 친구 카드로 만들어, 주차 중 실제로 켜 보면 차가 확인해 카드가 모이는 Pleos Connect용 차량 기능 도감입니다.

- 시연 영상: `video/Cubie_demo.mp4`(65.5초 편집본 · 한글 자막 · 실제 화면 1배속) · `video/Cubie_demo_raw.mp4`(후속 검증 원본) · `video/Cubie_first_discovery_raw.mp4`(실내등 첫 발견 원본)
- 설치 파일: `apk/AutoPixie_Cubie_release.apk` (버전 0.4.0)
- 현대자동차그룹 「차량용 앱 개발 공모전」 1차 제출 · 오토픽시

## 1. 30초 요약

| 무엇을 | 어떻게 |
|---|---|
| 빈 칸 = 기능 이름 + 숨은 친구 | 바인더 100칸. 이 차에 있는 기능은 이름이 보이고, 그 기능에 사는 친구는 실루엣으로 숨어 있음 |
| 바로 찾기 | 빈 칸을 누르면 「어디 있나 · 켜는 법」이 바로 나옴(공식 취급설명서 요약·출처). 바인더 위 「오늘의 수수께끼」는 놀이용 |
| 차에서 직접 켜기 → 차가 확인 | 앱을 열어 둔 채 주차 중 기능을 켜면, Vehicle SDK가 보낸 꺼짐 → 켜짐 변화로 카드가 생김. 열 때 이미 켜져 있던 기능·다시 켠 것은 카드가 되지 않음 |
| 친구 카드 | 친구 그림·이름 · 좋아하는 날(쓰면 좋은 때) · 만난 날짜 + 출처 |
| 차가 못 읽는 기능 | 「설명서 퀴즈 카드」 — 세 지선다 퀴즈. 은색 테두리로 구분하고 「켜 본 기능」으로는 세지 않음 |
| 계절 카드 | 11~2월에 처음 핸들 열선을 켜면 「겨울 따끈이」 + 날짜 도장 |

앱은 **주차 중에만** 열리고, 차를 **조작하지 않고 읽기만** 하며, **네트워크를 쓰지 않습니다**.

## 2. 이번 제출 범위 (0.4.0)

바인더 100칸 중 카드 자료는 13장(차가 확인 8 + 예비 1 + 설명서 퀴즈 4)이고, 나머지 칸은 물음표(12월 PT까지 채울 계획)입니다. 앱은 카드마다 지원을 확인해, 이 차에서 지원이 확인되지 않은 카드는 숨기고 완성률에서도 뺍니다. Pleos Connect 에뮬레이터 차에서는 **10장(차가 확인 6 + 설명서 퀴즈 4)**이 활성입니다.

## 3. 사용하는 Pleos SDK·API

- **Vehicle SDK 2.3.2** — 카드마다 `check…Capabilities`(지원 확인) → `get…`(현재 값) → `register…`(변화 구독). 예: 핸들 열선 `checkHvacSteeringWheelHeatCapabilities` · `getHvacSteeringWheelHeatState` · `registerHvacSteeringWheelHeatState`.
- **주차 중에만 열기** — `getCurrentGearSelectionState` · `registerGearSelection`, Android `CarUxRestrictionsManager`. 제한 정보를 받지 못하면 잠급니다.
- **타이어 공기압 경고** — `getTelltalesInfo` · `registerTelltales`. 카드가 아니라 걱정하는 큐비와 안내로만 표시.
- **쓰지 않는 것** — 차량 제어(set) 0, 앱 인터넷 권한 0. 위치(FusedLocation)·음성(TextToSpeech·SpeechToText)은 1차에서 쓰지 않습니다(위치·식별정보를 쓰지 않는 원칙, 말을 걸지 않는 앱 원칙).

## 4. 심사위원용 가장 짧은 실행 순서

1. Pleos Connect 에뮬레이터(v2.1)를 켭니다.
2. 설치: `adb -s <DEVICE_SERIAL> install apk/AutoPixie_Cubie_release.apk`
3. Virtual Console에서 기어 **Park**, 속도 **0**, 핸들 열선 **Off**로 둡니다.
4. 앱 목록에서 「큐비 도감」을 엽니다 → 바인더 화면.
5. 「핸들 열선」 칸을 눌러 위치·켜는 법을 본 뒤, Virtual Console에서 핸들 열선을 **Off → Low**로 바꿉니다 → 따끈이 카드가 뒤집히며 나타납니다(11~2월이면 겨울 따끈이 + 날짜 도장). 카드를 눌러 내용을 봅니다.
6. 카드가 **안** 생기는 경우: 핸들 열선을 Off → Low로 다시 바꿔도 카드 수·완성률은 그대로입니다. 다른 기능을 Console에서 미리 켜 둔 채 앱을 열면 그 기능은 카드가 되지 않습니다.
7. 「스마트 트렁크」 칸을 눌러 퀴즈를 풉니다(오답이면 다시 풀 수 있음).
8. Virtual Console에서 기어를 **Drive**로 바꿉니다 → 입력이 곧바로 닫히고 「큐비가 잠드는 시간이에요」 약 2초 뒤 홈 화면. Park로 되돌리고 앱을 다시 열면 바인더로 돌아옵니다.

시연용 입력을 쓰는 화면에는 「시연용」이 계속 표시되고, 실제 기록과 섞이지 않습니다.

## 5. 소스에서 빌드

JDK 17, Android SDK 35, Gradle 8.10.2(wrapper), AGP 8.8.2, Kotlin 2.0.0, 공개 Pleos Vehicle SDK 2.3.2가 필요합니다. `android/local.properties`에 `sdk.dir`을 본인 Android SDK 경로로 지정합니다(이 파일과 서명 설정은 저장소에 넣지 않음).

```powershell
cd android
.\gradlew.bat :app:assembleRelease --no-daemon --max-workers=1
```

기본 빌드는 서명되지 않은 APK입니다. 본인 키로 서명하려면 `android/signing.local.properties`에 다음을 지정한 뒤 `:app:prepareReleaseApk`를 실행합니다(키·비밀번호 파일은 저장소 밖에 보관, 경로 구분자는 `/`).

```properties
storeFile=<외부_키_파일>
storePasswordFile=<외부_비밀번호_파일>
keyAlias=<키_별칭>
keyPasswordFile=<외부_비밀번호_파일>
```

다른 키로 서명된 앱이 이미 설치돼 있으면 덮어 설치되지 않습니다. 이때 앱 삭제는 앱 기록도 지우므로 시험용 환경에서만 합니다.

## 6. 테스트 환경

- Pleos Connect 에뮬레이터: 제공 AVD 버전 표기 v2.1(시험 AVD `Pleos_Connect_v2.1_clean`), Android Emulator 37.2.12(build 16428233), AAOS API 34, x86_64.
- 화면 2560×1440, 160 dpi. 앱은 차량 화면 옆 앱 창 안에 표시됩니다.
- 앱: min SDK 28, compile/target SDK 35, versionName 0.4.0, versionCode 3, 앱 id `ai.upet.app`(개발 초기 이름을 그대로 둠).
- 지원 확인은 Virtual Console 값이 아니라 SDK의 capability 응답과 실제 읽기 값으로 판정합니다. 미지원 값을 지원으로 바꾸거나 SDK·AVD 설정을 고쳐 우회하지 않습니다.

## 8. 안전·개인정보

- 기어 P이고 주행 제한이 없을 때만 도감이 열립니다. D가 되면 입력을 닫고 홈으로 돌아가 운전 화면을 비켜 줍니다.
- 와이퍼·전조등처럼 주차 중에 켤 이유가 없는 기능은 카드로 만들지 않습니다.
- 카드 기록(카드 번호·만난 날·계절 도장)은 서버 없이 차 안에만 저장합니다. 위치·식별정보는 쓰지 않습니다.

## 9. 알려진 한계

- 실차가 아닌 Pleos Connect 에뮬레이터에서만 검증했습니다.
- 에뮬레이터 차에서 좌석 통풍(켜짐 신호 미확인)·드라이브 모드(「지원하지 않음」 응답)는 숨겨지고, 예비 카드 사이드미러 열선은 켜기 제어를 확인하지 못해 활성하지 않았습니다.
- 주행 중 잠들기 → 홈: 에뮬레이터에서 D 전환 뒤 약 2.1초(2,070 · 2,138 ms) 만에 홈, P에서 다시 열면 기록 유지를 확인했습니다. 회색 「주행 중에는 사용할 수 없습니다」 화면은 차 시스템의 안내입니다.
- 이전 개발 단계(학습 화면·질문 답)의 코드 일부가 기능 플래그로 꺼진 채 남아 있으며, 이번 제출에서는 쓰지 않습니다.

- 새 따끈이 그림으로 기기 녹화를 다시 했습니다. 현재 상태의 전체 흐름 원본은 카드 7/10이 저장된 상태에서 시작하며, 실내등과 핸들 열선을 다시 켜도 카드 수는 늘지 않습니다.
- 실내등을 처음 껐다 켰을 때 6/10에서 7/10으로 발견한 실제 장면은 별도 첫 발견 원본의 약 33초에 있습니다. 발견 기록을 지우거나 첫 발견을 재연하지 않았습니다. 두 원본 파일은 모두 편집하지 않은 기기 녹화입니다.
- 현재 원본의 실내등 설명은 이미 만난 카드의 설명입니다. 미발견 빈 칸 안내는 첫 발견 원본의 약 6초에 있습니다.
- 편집본은 두 원본의 실제 장면만 1배속으로 연결하고 대기 구간 일부를 덜었습니다. 상단에 원본 A·B와 에뮬레이터·Console 입력을 표시했고, 한글 자막은 앱 화면 밖에 배치했습니다.
